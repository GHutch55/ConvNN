# CNN Learning Project (PyTorch)

This project is a small hands-on implementation of a Convolutional Neural Network (CNN) built using PyTorch.

## Purpose

The goal of this project is to develop a foundational understanding of:

- How CNNs process image data
- How training and evaluation loops work
- How backpropagation and optimization function in practice
- How a full deep learning pipeline is structured

This was built as a learning exercise to prepare for research work involving deep learning and computer vision.

## Dataset

The model is trained on the CIFAR-10 dataset, which contains 32x32 color images across 10 classes.

## Features

- CNN implemented from scratch using PyTorch modules
- Data loading and augmentation pipeline
- Training and evaluation loops
- Accuracy and loss tracking per epoch
- Model checkpoint saving and loading
- Basic inference pipeline
- Training curve visualization

## Notes

This is not a production system. The focus is on clarity and understanding rather than optimization or maximum accuracy.
